# 实验记录模板

复制本文件后填写；以下空项表示待填写，不是已有实验结果。

## 基本信息

- 实验编号、日期、负责人：
- 对应代码提交编号：
- 本次想验证的问题：
- 算法名称及所属类别（课堂 / 参考 / 近期）：
- 论文、实现来源、版本及本项目的修改：
- 是否使用预训练检查点，来源是什么：

## 环境和数据

- 操作系统、语言版本、依赖版本、CPU / GPU：
- 数据来源、版本、文件校验值：
- 清洗、过滤和特征处理规则：
- 训练 / 验证 / 测试划分规则及各自规模：
- 评分转相关性标签的规则：
- 怎样防止验证、测试信息进入训练特征：
- 随机种子及生效位置：

## 训练与评估

- 配置文件路径和完整运行命令：
- 关键参数、调参范围及最终选择依据：
- 负采样、序列截断、早停规则（不适用时注明）：
- 候选集合、已评分电影过滤范围和冷启动处理：
- 指标定义、Top-K、计算范围和汇总方法：
- 训练时间、评估时间及资源使用情况：

## 结果与结论

- 验证集结果、测试集结果及对应表格路径：
- 图表和推荐示例路径：
- 与其他算法比较时，哪些条件保持一致：
- 观察到了什么，证据是什么：
- 失败情况、限制和不能完全复现的环节：
- 下一步要做什么：
