# 课程要求与待确认事项

根据课程提供的《Group Project Tutorial》整理，当前项目对应 **Project 1：Movie Recommendation**。这份清单用于安排工作，具体要求以课程原文和教师后续说明为准。

## 提交和展示

- 小组不超过 5 人，选出组长，按课程说明提交成员名单。
- 进行 5 分钟课堂展示，说明任务、数据、三个算法、评估和主要发现。
- 通过课程 Canvas 提交技术报告、源代码、README 和允许提交的演示材料。
- 技术报告需说清数据处理和分析过程、发现及结论。
- README 必须包含运行说明、软件要求、随机种子、数据集引用和结果表或图的位置。

## Project 1 检查清单

### 数据集信息（20%）

- [ ] 使用 MovieLens 1M，说明用户、电影、评分三个文件的内容和关联方式。
- [ ] 展示数据形状、缺失值总数、存在缺失值的列、数据基本信息。
- [ ] 展示各列唯一值数量和字段类型。
- [ ] 完成课程原文中的 “Create the comparison dataset”。该表述未说明具体含义，需向教师或助教确认后再实施。
- [ ] 阅读数据包 README，引用 GroupLens，遵守数据使用限制。

### 数据探索和预处理（20%）

- [ ] 检查数据特点、分布和缺失情况，给出相关图表。
- [ ] 根据数据类型解释缺失值处理、编码，以及是否需要标准化或归一化。
- [ ] 记录可复现的训练集、验证集和测试集划分方式。
- [ ] 说明如何将评分转成相关性标签。
- [ ] 说明怎样防止留出评分泄漏到训练特征中。

### 算法定义（30%）

必须正好选三个推荐算法，三个位置分别是：

1. **课堂算法**：从课堂讲授的方法中选择，具体选择待定；先核对课件。
2. **指定参考算法**：从 LightGBM、LightFM、DCN V2、DeepFM、BPR、DIN 中选择一个复现。
3. **指定近期算法（2024–2025）**：从 LRURec、ICSRec、Mamba4Rec 中选择一个。

课程提醒：复现 ICSRec 时应说明是否使用预训练检查点；Mamba4Rec 的文档环境涉及 CUDA、causal-conv1d 和 mamba-ssm，选型前需核对设备及依赖条件。

算法选择、论文和实现来源、关键参数、修改内容和复现范围，都要在实际确定后记录。

### 电影推荐（20%）

- [ ] 对选定用户，每个算法推荐至少 5 部不在其已观察评分历史中的电影。
- [ ] 展示片名和类型。
- [ ] 比较三个算法给出的推荐，解释相同和不同之处。

### 系统展示（10%）

- [ ] 用网页、移动端、Notebook 或等效交互界面接收用户或示例档案并显示推荐。
- [ ] 课程未要求精细部署，先保证功能可以演示。

## 需要小组确定的内容

- 三个具体算法，以及课堂算法对应的课件内容。
- 开发语言、环境、运行设备和展示方式。
- 分工、内部时间安排，以及实际提交截止时间。
- 数据划分、评分相关性阈值、评价指标、候选电影集合、负采样方法和随机种子。
- “comparison dataset” 的具体含义。

这些事项尚未确定，不代表已经完成。课程 Project 1 没有在该页明确指定具体评价指标；不能直接把 Project 2 的 NDCG@10、Recall@10 或 LightGBM 必选要求当成 Project 1 的硬性要求。
