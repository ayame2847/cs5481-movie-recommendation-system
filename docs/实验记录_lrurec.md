# 实验记录：LRURec

## 本次实验

- 模块：近期算法，LRURec（WSDM 2024）。实验执行日期：2026-11-17。
- 来源：Zhenrui Yue, Yueqi Wang, Zhankui He, Huimin Zeng, Julian McAuley, Dong Wang. *Linear Recurrent Units for Sequential Recommendation*. WSDM 2024, pp. 930–938. [论文](https://doi.org/10.1145/3616855.3635760)。[官方实现](https://github.com/yueqirex/LRURec)。
- 官方固定提交：`e02a559bd8c42342f5c53d69cefea2589becb22c`。项目训练入口为 `src/lrurec_project.py`，哈希与实际运行记录一致。
- 不使用预训练模型，从种子42随机初始化。运行命令和输出说明见 [运行说明](LRURec运行说明.md)。

## 数据与协议

复用组内MovieLens 1M清洗与划分：train共988134行，其中563206条正例；val共6037行，test共6038行。评分≥4视为正例。训练只使用train正例，不伪造验证答案。有效训练、验证、测试用户均为6035人。原始6038名有test目标的用户中，有3人不满足本次测试条件；完整资格见 `results/lrurec/user_population.csv`。

使用3706部已评分电影的固定词表，181部无训练正例。训练与评估不得额外用测试评分估计特征或参数。完整过滤历史与共享split的时间局限见运行说明；词表包含留出集合中出现的物品ID属于预先固定的目录口径，并不等于完全未知物品的冷启动测试。

数据文件SHA256、脚本SHA256和官方模型文件SHA256见 `results/lrurec/run_metadata.json`。这份记录保存实际执行参数，不把Notebook中的临时路径当作通用运行要求。

## 环境与参数

- Python 3.13.16，PyTorch 2.14.1+cu130，numpy 2.4.6，pandas 2.2.3，Tesla T4。
- 模型参数量341691；隐藏维度64，LRU块数2，序列长200，dropout及LRU dropout均为0.2。
- AdamW，学习率0.001、权重衰减0.01（bias和layer_norm不衰减），eps=1e-9，梯度裁剪5。
- 训练batch128，评估batch128，num_workers=0；下一项全词表交叉熵，padding标签忽略。
- 每轮验证；以验证Recall@10选权重，最多50轮、patience=10。此次第38轮最佳，第48轮结束；没有根据测试结果继续调参。
- 本次为单个固定配置、单个种子实验，没有进行系统超参数搜索。不能把它称为LRURec的全局最优配置。

## 实际结果

- 最佳验证Recall@10：0.26926263463131733。
- 最终测试Recall@10：0.24341342170671085。
- 最终测试NDCG@10：0.12848255196644623。
- 测试用户数6035；逐用户等权平均，完整结果见 `results/tables/10_lrurec_metrics.csv`。
- 训练及验证累计耗时约437.59秒，最终测试约3.42秒。耗时含运行环境差异，不作为跨硬件效率结论。
- 测试推荐与最终展示推荐分别见 `11_lrurec_test_top5.csv`、`12_lrurec_final_top5.csv`，各为原始UserID 1–5每人5部电影，展示片名、类型和得分。

## 核验与限制

已核验提交脚本与运行元数据哈希一致；6035名用户的各项指标符合排名公式，逐用户均值与汇总表一致；有效用户范围与资格表一致；最佳轮次与逐轮验证表一致；推荐表的电影不重复、排名完整，测试命中标记与目标ID一致。

执行后的Notebook显示短跑成功返回和正式运行输出目录，并展示了结果。子进程的逐轮训练stdout没有完整保存在Notebook中，逐轮证据以validation_history.csv及运行元数据为准。复核包不含权重或完整原始数据，本次未独立重跑GPU训练，也未从原始评分重新验证每条推荐的过滤；脚本在实际执行中对过滤、目标和有限得分作了断言。

本次结果是项目适配协议下的实验，不应直接与官方示例或旧提交0.214004的Recall@10作同协议提升比较。MF/BPR尚需按同一测试用户、词表和过滤规则输出结果，才能解释模型间差异。还需讨论单种子波动、低交互用户、181部无训练正例电影和共享划分时间局限。

模型只使用电影ID序列，没有使用电影类型或用户人口属性。展示中的类型相似性可以作为定性观察，不能据此证明因果关系或总体推荐质量更好。
