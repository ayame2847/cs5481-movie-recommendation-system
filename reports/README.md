# 报告和展示材料

这里保存技术报告和展示材料。现有 A 部分报告为 `A_data_report.md` / `A_data_report_en.md`，B 部分 MF 报告为 `B_MF_report.md`。最终小组报告和 5 分钟展示仍待整合。

技术报告应覆盖任务和数据、探索与预处理、三个算法、实验设置、评估结果、推荐示例、结论与限制，以及数据、论文和第三方代码的引用。

展示材料围绕任务、数据、三个算法、评估和主要发现安排内容。结果图表引用 `results/` 中可追溯的文件；提交前核对报告、README、配置和实际运行结果是否一致。

BPR独立实验报告为 `BPR_实验报告.pdf`，其评估用户和候选范围尚未与MF/LRURec统一，不直接用于同口径三算法比较。
